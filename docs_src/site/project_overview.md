# Project Overview

## p04_ardia_guidotti_kroencke_2024

Replication of **Ardia, Guidotti, Kroencke (2024, JFE)**: *Efficient Estimation
of Bid-Ask Spreads from Open, High, Low, and Close Prices*. UChicago FinM Data
Pipeline final project.

Reference implementation used as the oracle for our tests:
<https://github.com/eguidotti/bidask>.

See the repository [README](https://github.com/zhenqili2004/p04_ardia_guidotti_kroencke_2024)
for the full paper summary, task list, and data sources, and
[PROJECT_SPEC.md](https://github.com/zhenqili2004/p04_ardia_guidotti_kroencke_2024/blob/main/PROJECT_SPEC.md)
for the course rubric.
